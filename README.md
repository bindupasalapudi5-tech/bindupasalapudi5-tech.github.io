# Pasalapudi Bindu Sailaja | AI/ML Engineer Portfolio

A personal portfolio website for **Pasalapudi Bindu Sailaja**, an AI/ML engineer who builds and deploys end-to-end machine learning and NLP applications. It is a single-page site that works on phones, tablets, and desktops.

**Live site:** [bindupasalapudi5-tech.github.io](https://bindupasalapudi5-tech.github.io)

## Features

- Single-page layout with smooth scrolling between sections
- Dark mode by default, with a light/dark toggle that remembers your choice
- Responsive design with a collapsible menu on mobile
- Experience shown as a timeline
- Project cards with GitHub and live demo links
- Subtle animations that respect the "reduce motion" setting on a visitor's device
- One self-contained HTML file with no build step and no frameworks

## Run it locally

1. Download or clone this repository:
   ```bash
   git clone https://github.com/bindupasalapudi5-tech/bindupasalapudi5-tech.github.io.git
   ```
2. Open `index.html` in any modern browser.

No installation is needed.

## Deploy with GitHub Pages

1. Name the repository `bindupasalapudi5-tech.github.io`.
2. Make sure the main file is called `index.html`.
3. Go to **Settings > Pages**, choose the `main` branch, and save.
4. Your site will be live at `https://bindupasalapudi5-tech.github.io` after a minute or two.

## Customize

- **Text and links:** edit the content directly in `index.html`.
- **Colors:** change the values at the top of the `<style>` block, under `:root` for light mode and the dark theme blocks for dark mode.
- **Default theme:** change `data-theme="dark"` on the `<html>` tag to `"light"`.
